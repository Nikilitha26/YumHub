Path Method Description
Users Table
/users/ GET Gets all of the users
/users/:id GET Gets a single by id
/users/ POST Adds a user
/users/:id DELETE Deletes a by id
/users/:id PATCH Edits all information of a user by id
Login/Signup Table
/users/login POST Logs an existing user in
/users/ POST Adds a new user
Posts Table
/posts/ GET Gets all of the posts
/posts/:id GET Gets a single post by id
/posts/ POST Adds a post
/posts/:id DELETE Deletes a post by id
/posts/:id PATCH Edits all information of a post by id
